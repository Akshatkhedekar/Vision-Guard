# Project Statement — VisionGuard

## Problem Statement
Manual inspection of road surfaces is time-consuming and can be inconsistent when large numbers of images must be reviewed. VisionGuard is a computer-vision prototype that processes road images, identifies candidate surface-defect regions, estimates their severity, and summarizes results across multiple images.

## Scope
The project covers image preprocessing, candidate-region detection, contour-based feature extraction, severity estimation, batch analytics, and PDF reporting. It is an academic prototype and does not claim to replace certified road inspection or a trained production object detector.

## Target Users
- Computer Vision students demonstrating image-processing concepts.
- Academic evaluators reviewing an applied CV workflow.
- Researchers/prototypers experimenting with interpretable road-image analysis.

## High-Level Features
1. Image upload and preprocessing.
2. Candidate defect detection using adaptive thresholding and morphology.
3. Contour-based feature extraction and severity estimation.
4. Batch analytics across multiple images.
5. PDF report generation.
6. Automated validation tests.
